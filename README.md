# ROBO / Олимпиадный навигатор

Интерактивный полностью автономный учебник для подготовки к ВсОШ по информатике, профиль «Робототехника», 10–11 класс.

## Как запустить

1. Распакуйте ZIP целиком.
2. Откройте `index.html` двойным кликом в Safari, Chrome или другом современном браузере.
3. Для работы **не нужен интернет, сервер, npm, Python или установка зависимостей**.
4. Не удаляйте файлы `app.js`, `data.js`, `style.css` или папку `assets`.

## Что внутри

- **19 подробных глав** с объяснением формул и алгоритмов решения;
- **37 разборов** заданий из 3 PDF с теоретическими вариантами (13 региональных, 14 муниципальных с двумя подпунктами последнего, 8 школьных с двумя подпунктами последнего). Пункты M14 и S08 разбиты на отдельные вопросы; суммарно 37 карточек;
- **150 тренировочных задач** по 15 темам с проверкой после каждого вопроса, объяснением и подсказками;
- отдельная симуляция **практического задания «Инспектор склада»**, подсчёт чётности LED, критерии оценивания;
- локальное сохранение пройденных уроков, верных заданий и статистики тестов;
- таймер 25 / 60 / 180 минут;
- поиски и фильтры, мобильная адаптация, интерактивные исходные страницы PDF, крупные авторские схемы и фрагменты рисунков.

## Структура

- `index.html` — страница приложения;
- `style.css` — полностью автономный адаптивный дизайн;
- `app.js` — интерфейс, проверка ответов, тренажёр, симулятор, таймер, сохранение прогресса;
- `data.js` — уроки, 37 разборов и 150 самостоятельных вопросов;
- `sources/` — четыре оригинальных PDF, переданных пользователем;
- `assets/` — изображения 27 страниц оригиналов, 19 авторских SVG-схем для уроков и 17 отдельных увеличенных фрагментов рисунков из PDF;
- `illustrations.js` — привязка рисунков к главам, конкретным заданиям и тренажёру;
- `make_illustrations.py` — скрипт генерации всех учебных SVG и извлечения рисунков из PDF;
- `build_data.py` — исходный скрипт формирования обучающего контента и банка вопросов.

## Про исходные задачи

Численные ответы рассчитаны по условиям PDF. Карточки с неопределённым ответом **не участвуют в автоматической проверке**: например, задача про радар с отсылкой на отсутствующий в исходном PDF рисунок и задача про тягу с коэффициентом трения, но без массы/нормальной реакции. Они содержат выводимые формулы и необходимые оговорки. Для сложных рисунков работа с исходной схемой остаётся обязательной; источник доступен рядом с карточкой.

Учебный материал ориентирован на присланные варианты олимпиад за 2025/26 и 2026/27 учебные годы; актуальные правила вашего этапа могут отличаться.

## Конфиденциальность

Приложение не делает сетевых запросов, не содержит аналитики и аккаунтов. Прогресс хранится в `localStorage` вашего браузера. При открытии файла под новым путём браузер может показать отдельное хранилище прогресса.
